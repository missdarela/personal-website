# Personal Portfolio Website

A modern, responsive, and beautiful personal portfolio website built with HTML, CSS, and JavaScript.

## Features

- **Fully Responsive**: Looks great on all devices
- **Modern UI/UX**: Clean and professional design
- **Smooth Animations**: Subtle animations for better user experience
- **Easy to Customize**: Change colors, content, and images easily
- **Fast Loading**: Optimized for performance
- **SEO Friendly**: Structured for better search engine visibility

## Customization

### Personal Information
1. Open `index.html` in a text editor
2. Update the following sections with your information:
   - Update the `<title>` tag with your name
   - Update the hero section with your name and profession
   - Update the about section with your personal information
   - Update the skills section with your skills and proficiency levels
   - Add your projects to the projects section
   - Update the contact information with your details

### Colors
To change the color scheme, modify the CSS variables in the `:root` selector in `css/style.css`:

```css
:root {
    --primary-color: #6c63ff;
    --secondary-color: #4d44db;
    --dark-color: #2d2e32;
    --light-color: #f9f9f9;
    --text-color: #555;
    --text-dark: #333;
    --text-light: #777;
    --white: #ffffff;
}
```

### Images
1. Replace the profile placeholder in the hero section with your profile image
2. Add your project screenshots to the projects section
3. Update the favicon (optional)

### Fonts
The website uses Google Fonts (Poppins). You can change this by:
1. Go to [Google Fonts](https://fonts.google.com/)
2. Select a different font
3. Update the link in the `<head>` section of `index.html`
4. Update the `font-family` in the CSS

## Deployment
